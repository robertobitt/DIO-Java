## 💻 Sobre o Projeto

Simular uma máquina de banho para pets utilizada em um Petshop, com entrada e saída personalizada de animal, limpeza de máquina e controle de estoque para água e shampoo.

Este projeto foi desenvolvido como parte do bootcamp de Java e IA da **Digital Innovation One (DIO)**.

### ⚙️ Funcionalidades
A máquina do código tem as seguintes funções, considerando consumo e estoque dos insumos.
- Dar banho no pet;
- Abastecer com água;
- Abastecer com shampoo;
- Verificar nivel de água;
- Verificar nivel de shampoo;
- Verificar se tem pet no banho;
- Colocar pet na maquina;
- Retirar pet da máquina;
- Limpar maquina.
